📂 Daftar Proyek

1. Cikandung Wisata

Website informasi wisata Mata Air Cikandung yang berlokasi di Kabupaten Sumedang, Jawa Barat.

Website ini dirancang untuk memperkenalkan destinasi wisata melalui informasi lokasi, dokumentasi foto dan video, peta lokasi, serta simulasi pemesanan kunjungan dengan e-ticket digital.

Teknologi utama:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Google Maps
- QRCode.js

Fitur utama:

- Informasi wisata
- Galeri foto dan video
- Simulasi pemesanan kunjungan
- E-ticket digital dengan kode QR
- Peta lokasi wisata
- Musik latar

Folder proyek: ""cikandung-wisata/"" (./cikandung-wisata/)

Dokumentasi lengkap mengenai proyek ini tersedia pada "README Cikandung Wisata" (./cikandung-wisata/README.md).
