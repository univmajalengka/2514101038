## 📌 Tentang Proyek

Cikandung Wisata merupakan website informasi wisata Mata Air Cikandung yang berlokasi di Kabupaten Sumedang, Jawa Barat.

Website ini dikembangkan sebagai proyek tugas mata kuliah **Pengembangan Aplikasi Berbasis Web**. Tujuannya adalah memperkenalkan destinasi wisata melalui tampilan website yang informatif, menarik, dan interaktif.

---

## ✨ Fitur Website

- 🏞️ **Informasi Wisata** — Menampilkan informasi destinasi, lokasi, jam operasional, harga tiket, dan fasilitas.
- 📸 **Galeri Foto** — Menampilkan dokumentasi foto Mata Air Cikandung.
- 🎬 **Galeri Video** — Menyediakan dokumentasi video suasana dan aktivitas di kawasan wisata.
- 🎟️ **Pemesanan Kunjungan** — Formulir simulasi pemesanan berdasarkan data pengunjung.
- 🎫 **E-Ticket Digital** — Membuat tiket digital yang dilengkapi kode booking dan kode QR.
- 📍 **Peta Lokasi** — Menampilkan lokasi wisata melalui Google Maps.
- 🎵 **Musik Latar** — Tombol untuk menyalakan dan mematikan musik secara manual.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |

| HTML5 | Membuat struktur halaman website |
| CSS3 | Mengatur desain dan tampilan website |
| JavaScript | Menambahkan interaksi dan fungsionalitas |
| Bootstrap 5 | Membantu membuat layout responsif |
| Google Maps | Menampilkan peta lokasi wisata |
| Bootstrap Icons | Menampilkan ikon pada antarmuka |
| QRCode.js | Membuat kode QR pada e-ticket |
| html2canvas | Mendukung pengunduhan e-ticket sebagai gambar |

## 📂 Struktur Folder

```text
cikandung-wisata/
├── README.md
├── index.html
├── style.css
├── script.js
└── assets/
    ├── Foto/
    ├── videos/
    └── file-musik.mp3
```

**Keterangan:**

- `index.html` — Halaman utama website.
- `style.css` — Pengaturan desain dan tata letak.
- `script.js` — Pengaturan interaksi dan fungsi website.
- `assets/Foto/` — Folder dokumentasi foto.
- `assets/videos/` — Folder dokumentasi video.
- `file-musik.mp3` — File audio untuk musik latar.

## 🚀 Cara Menjalankan

1. Unduh atau clone repository ke komputer.
2. Buka folder `cikandung-wisata`.
3. Pastikan file dan folder pendukung tersedia sesuai struktur proyek.
4. Buka `index.html` menggunakan browser.
5. Pastikan koneksi internet tersedia untuk memuat library eksternal dan Google Maps.

## ⚠️ Catatan

- Fitur pemesanan dan e-ticket merupakan simulasi untuk keperluan tugas perkuliahan, bukan sistem reservasi resmi.
- Informasi harga tiket, fasilitas, dan jam operasional perlu dikonfirmasi kembali kepada pengelola wisata.
